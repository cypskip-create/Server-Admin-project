# HTTPS with ZeroSSL

ZeroSSL trial terms, certificate lifetimes and account entitlements can change; check the current ZeroSSL dashboard and official issuance docs before relying on a six-month certificate. ACME issuance may require account email plus External Account Binding (EAB) key ID and HMAC from the ZeroSSL account. Keep these secrets private.

For Apache, use an ACME client that supports ZeroSSL's ACME directory and EAB (for example, current Certbot with the appropriate plugin or acme.sh). Issue certificates only after DNS resolves to the VPS and inbound 80/443 work. Configure one certificate with SAN coverage for the main, `app`, and `admin` names; install its full chain at `/etc/ssl/certs/campusflow-fullchain.pem` and private key at `/etc/ssl/private/campusflow-key.pem` (root-owned, key mode 0640 with a suitable Apache group). The vhost template references these paths. Redirect HTTP to HTTPS; use TLS 1.2/1.3; set `SESSION_SECURE=true`. Follow the ACME client's renewal mechanism and reload Apache after successful renewal, then verify with `curl -I https://app.example.edu` and `openssl s_client -connect app.example.edu:443 -servername app.example.edu`. Never commit EAB credentials or private keys.
